# Security policy

This policy covers every repository in the NASty project.

## Reporting a vulnerability

Please report security issues privately, not in public issues, discussions or pull requests.

Use GitHub's private vulnerability reporting: open the affected repository, go to
**Security → Report a vulnerability**, and describe the issue. For example:
<https://github.com/nasty-project/nasty/security/advisories/new>

Helpful details:

- affected repository and version (or commit)
- steps to reproduce, or a proof of concept
- impact as you understand it

You will get a reply in the advisory thread. Once a fix is released, the advisory is
published and reporters are credited unless they prefer otherwise.

## Supported versions

Fixes go into the latest release of each project. Please check that the issue still
exists there before reporting.
